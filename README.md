# Abdulbasit Hassan Portfolio

A responsive portfolio website for Abdulbasit Hassan, an administrative virtual assistant.

## Run locally

Requires Node.js 20+ and pnpm.

```bash
pnpm install
pnpm dev
```

Open the local URL shown by Vite.

## Build for production

```bash
pnpm build
pnpm preview
```

The production files are generated in `dist/`.

## Deploy on GitHub

Upload the contents of this folder to a GitHub repository. For GitHub Pages, configure the site to build with `pnpm build` and publish the generated `dist` directory, or deploy the repository with a Vite-compatible host such as Vercel or Netlify.
